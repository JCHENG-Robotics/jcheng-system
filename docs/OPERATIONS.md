# 运行手册（占位）

> M1 没有运行时可部署；本文件只记录未来运行手册的边界。

## M1

- 不启动 ROS 节点。
- 不连接机器人。
- 不发送运动命令。
- 不重启厂商容器。

## M3 起补充

- 启动顺序：厂商栈（预先运行）-> 硬件桥（只读）-> 安全 -> 运动 -> 权威 -> 网关 -> 使能。
- 停止/复位/锁存处理。
- 总线缓存重同步。
- 厂商节点崩溃的节点级恢复（不重启容器）。
- 证据采集与脱敏。
- 回滚到上一锁文件。

## 实机

任何实机步骤都必须带“单独授权、预检、监督人、证据”四项；
详见 `.github` 仓库的 `docs/hardware-workflow.md`。
